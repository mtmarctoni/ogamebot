# OGameBot

A Python bot to automate browser actions for https://lobby.ogame.gameforge.com/en_GB/hub, including Facebook authentication and session management.

## Features

- Automates browser login via Facebook
- Saves and restores browser session for persistent authentication

## Setup

1. Python 3.8+
2. (Recommended) Create a virtual environment:
   ```sh
   python3 -m venv venv
   source venv/bin/activate
   ```
3. Install dependencies (to be added)

## Usage

- Run the bot script to start browser automation.
